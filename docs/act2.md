# Акт II — рабочая версия

Автоматический переход через пять секунд после титра второго акта. Состав, общий банк и неиспользованные часы сохраняются. Зеркало требует согласия, не принимает голос автора, даёт Лидеру 15 секунд решить ничью, затем случайно выбирает из равных. Личный выбор не раскрывается; для будущей концовки требуется строгое большинство «Отпустить». После выбора временный список желаний удаляется; в профиле остаётся текст до 140 символов.

Гербарий: код 715294, после трёх ошибок блокировка 20 секунд, до трёх платных подсказок. Печатные текстовые карточки и полка: `/art/act2/herbarium-print.html` (печатать из браузера). Иллюстрации отдельных растений пока не добавлены.

Котёл: пять раундов, листы и кнопки распределены между телефонами. Полный рецепт остаётся на сервере, кроме спасательного режима после шести провалов. Покупки требуют 60% голосов, подсказки привязаны к текущему состоянию. Способности хранятся у игрока и расходуются один раз за акт. Смена рецепта требует подтверждения.

Проверки: `node --test opening/*.test.*`. Полные прохождения для 3–6 игроков; правила рецептов, согласие, авторство, чужие кнопки, экономика, спасательный режим и права доступа.

Ограничения этой версии: новых голосовых записей нет, пожелания выводятся текстом без синтеза речи. Портрет Спраут не подключён: генерация отклонена. Видение шарфа и цветок пока оформлены средствами интерфейса. Финальные три удара используют звуковой синтез; шестой обрывается, через секунду звучит существующая запись гудка. Нужна проверка на физических телефонах и телевизоре.
