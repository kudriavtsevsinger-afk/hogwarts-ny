# Тайна последней полуночи

Персональная многопользовательская игра для шести участников: Олега, Симы, Маши, Вани, Лизы и Амины. Запускается на главной странице Worker. Участники заходят по QR-коду и выбирают себя по имени; отсутствующие участники не появляются в заставке. Для начала достаточно одного игрока.

До пролога игра не показывает портреты или название. Каждый участник по очереди отвечает на восемь вопросов с телефона. Затем на общем экране на фоне Кингс-Кросс по одному появляются портреты только присутствующих игроков, они собираются в общий ряд, и лишь после этого появляется логотип игры. Результат опроса и портрет с подходящей эмоцией показываются игроку лично.

## Визуальное правило игры

Все сцены с персонажами строятся на полноэкранном тематическом фоне. Персонажи вписаны в сцену поверх фона; они никогда не оформляются отдельными карточками или плитками. Имена, реплики и другой текст располагаются в нижней части экрана поверх сцены. Это правило действует для всех экранов игры.

Все 24 портрета шести участников (по четыре эмоции) включены в `avatar-static/portraits/`. Для создания комнаты не требуется загружать файлы.

Игра работает в Cloudflare Worker `hogwarts-new`, хранилище комнат — Durable Objects. Основной интерфейс находится в `avatar-static/opening/`, логика опроса — в `opening/quiz.mjs`, синхронизация комнаты — в `opening/worker.mjs`.

Общая заставка устроена как постер: крупные портреты плечом к плечу одним рядом у нижнего края, с небольшим перекрытием плеч. Логотип появляется в верхней части той же сцены; участники остаются на месте. Количество фигур определяется составом комнаты, порядок — Олег, Сима, Маша, Ваня, Лиза, Амина (отсутствующие пропускаются).
