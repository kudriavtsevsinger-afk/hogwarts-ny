# Хогвартс. Новогодняя ночь — техническая база игры

## Что это
Полноценный многопользовательский движок для вашего сценария (Пролог + 5 Актов).
Один ноутбук/телевизор показывает экран (`/hogwarts_ny`), игроки подключаются
с телефонов (`/hogwarts_ny/player`) по QR-коду. Один из игроков в начале
отмечает себя администратором и управляет темпом игры («Далее ➜»).

Полностью готовы и протестированы:
- Лобби + QR-вход + единственный администратор комнаты
- Конструктор внешности (лицо/брови/глаза/нос/губы/макияж/причёска/одежда)
  и рандомная способность, зависящая от выбранных черт
- Общая казна монет и платные подсказки
- Пролог + Акт I целиком, с двумя типами мини-игр:
  - `vote_choice` — голосование всех игроков за вариант (влияет на сюжет)
  - `fragment_cipher` — совместный шифр: подсказки раздаются по кругу между
    ВСЕМИ подключёнными игроками (работает для 3, для 6, для 10 — неважно),
    собрать его можно только обсуждая вслух то, что у каждого на экране

**Акты II–V** в коде — заготовки (`todo: true` в `worker/src/content/story.js`)
с локациями и сюжетными метками из вашего сценария, но без контента и мини-игр.
Это следующий шаг работы, не то, что уже готово.

## Как это устроено технически
Тильда не умеет запускать серверный код и WebSocket — поэтому игра живёт
отдельно, на Cloudflare Workers, а в dash.cloudflare.com добавляется **Route**,
который перехватывает только путь `/hogwarts_ny*` на вашем домене. Весь
остальной сайт как и раньше обслуживает Тильда.

- `worker/src/index.js` — роутинг запросов и раздача статики
- `worker/src/room.js` — Durable Object: по одному "виртуальному серверу"
  на каждую игровую комнату (компанию), вся синхронизация через WebSocket
- `worker/src/content/story.js` — весь текст и структура сюжета
- `worker/src/content/appearance.js` — варианты внешности и таблица способностей
- `public/host` и `public/player` — то, что видят на экране и на телефонах

## Локальный запуск для проверки (на своём компьютере)
```bash
npm install
npm run dev
```
Откроется адрес вида `http://localhost:8787/hogwarts_ny` — это и есть
host-экран. Для игрока откройте `http://localhost:8787/hogwarts_ny/player`
на телефоне в той же Wi-Fi сети (замените localhost на IP компьютера).

## Деплой на Cloudflare (прод)
1. Зарегистрируйтесь / войдите в dash.cloudflare.com, убедитесь что зона
   `kudriavtsev-on.ru` уже добавлена туда (раз Tilda через неё работает — она,
   скорее всего, уже подключена).
2. В терминале, в этой папке:
   ```bash
   npm install
   npx wrangler login      # откроет браузер для привязки аккаунта
   npx wrangler deploy
   ```
3. После деплоя откройте в dash.cloudflare.com → ваш домен → **Workers Routes**
   и добавьте маршрут:
   - Route: `kudriavtsev-on.ru/hogwarts_ny*`
   - Worker: `hogwarts-ny`
4. Готово — `https://kudriavtsev-on.ru/hogwarts_ny` и `.../hogwarts_ny/player`
   должны заработать, а остальной сайт на Тильде не тронут.

Если доступа к Cloudflare нет у меня — все 4 шага выше можно сделать
самостоятельно, они занимают 10 минут.
